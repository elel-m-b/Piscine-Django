## 🌊 About

The **Django Piscine** is an intensive learning experience within the **42 Network** curriculum, designed to immerse students in **web development** using the **Django framework**. Over the course of multiple modules, you'll progress from basic Python concepts to building complete web applications with databases, sessions, and advanced features.

This piscine follows the same philosophy as the C Piscine: **learn by doing**, with a new module introducing fresh concepts each day.

> *"The best way to learn web development is to build real applications."*

---

## 🏊 What is a Piscine?

A **piscine** (French for "swimming pool") is an intensive, project-based learning program where you:

### 🎯 Key Characteristics

- 📅 **Daily Modules**: Each day brings new concepts and challenges
- 🔄 **Sequential Learning**: Must complete modules in order
- 👥 **Collaborative**: Highly recommended to work with other students
- ⏱️ **Time-Limited**: Each repository auto-closes after one day
- 🔁 **Retryable**: Can retry modules without waiting
- 📊 **Peer Evaluation**: Must complete evaluations within two days

### ⚠️ Important Notes

- ✅ **Minimum 2 weeks** of dedicated work required
- ✅ **Submit daily** - even incomplete work is better than nothing
- ✅ **Can't validate with just 1-2 projects** - commitment is essential
- ✅ **Work with others** - collaboration is highly encouraged
- ✅ **Stay consistent** - regular progress is key to success

## 🛠️ Installation

### 1. Clone the Repository

```bash
git clone <your-repo-url>
cd django-piscine
```

### 2. Set Up Virtual Environment

```bash
# Create virtual environment

python3 -m venv venv

# Activate virtual environment
# On Linux/Mac:

source venv/bin/activate
# On Windows:

venv\Scripts\activate
```

### 3. Install Django

```bash
pip install django

# For specific module requirements:
pip install -r requirements.txt
```

### 4. Verify Installation

```bash
python --version
django-admin --version
```

### 5. Create Django Project (as needed per module)

```bash
django-admin startproject myproject
cd myproject
python manage.py runserver
```

To successfully validate the Django Piscine:

- [ ] Participate in **peer evaluations** within 2 days
- [ ] Dedicate **minimum 2 weeks** of focused work
- [ ] **Collaborate** with other students
- [ ] Validate **each project before moving to next**

### 🎯 Study Strategy

1. **Read Documentation First**
   - Django official docs are excellent
   - Understand concepts before coding
   - Reference documentation while working

2. **Code Daily**
   - Consistency beats intensity
   - Even 2-3 hours daily is valuable
   - Build muscle memory

3. **Test Everything**
   - Test each feature as you build
   - Use Django shell for quick tests
   - Debug systematically

4. **Ask Questions**
   - Use Slack/Discord communities
   - Pair program with peers
   - Review others' code

## 🐛 Common Issues & Solutions

<details>
<summary><b>Virtual Environment Issues</b></summary>

```bash
# If venv doesn't activate:
# Linux/Mac:
source venv/bin/activate

# Windows:
.\venv\Scripts\activate

# If still not working, recreate:
rm -rf venv
python3 -m venv venv
```

</details>

<details>
<summary><b>Django Not Found</b></summary>

```bash
# Ensure virtual environment is active
# Then reinstall Django
pip install --upgrade pip
pip install django
```

</details>

<details>
<summary><b>Database Connection Errors</b></summary>

```bash
# Check PostgreSQL is running
sudo service postgresql status

# Check database settings in settings.py
# Ensure credentials are correct
```

</details>

<details>
<summary><b>Migration Issues</b></summary>

```bash
# Delete migrations and database
rm -rf */migrations/*
rm db.sqlite3

# Create fresh migrations
python manage.py makemigrations
python manage.py migrate
```

</details>
