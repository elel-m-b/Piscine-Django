Django ships with its own default template engine, the Django Template Language (DTL). It lets you insert dynamic data and simple logic into otherwise static HTML files, using two kinds of syntax:

  • {% verbatim %}{{ variable }}{% endverbatim %} to output a value.
  • {% verbatim %}{% tag %}{% endverbatim %} to perform logic such as loops and conditions.

Blocks

A block is a named placeholder defined in a parent template with {% verbatim %}{% block name %}...{% endblock %}{% endverbatim %}. A child template that uses {% verbatim %}{% extends %}{% endverbatim %} can override that block to replace its content while reusing everything else from the parent. This page itself is a good example: it extends base.html and overrides the style block to load style2.css instead of the default style1.css.

The for ... in Loop

The for tag repeats a block of HTML once for every item in a list or queryset:

{% verbatim %} 
{% for item in item_list %}
    <li>{{ item }}</li>
{% endfor %}
{% endverbatim %}

Django also provides an {% verbatim %}{% empty %}{% endverbatim %} clause that is rendered when the list is empty, and loop helpers such as forloop.counter or forloop.first.

The if Control Structure

The if tag conditionally renders content, and supports elif and else just like Python:

{% verbatim %} 
{% if user.is_authenticated %}
    Welcome back!
{% elif guest_mode %}
    Browsing as a guest.
{% else %}
    Please log in.
{% endif %}
{% endverbatim %}

Displaying Context Variables

A view passes a Python dictionary, called the context, to render(). Every key of that dictionary becomes a variable the template can display with double curly braces, e.g. {% verbatim %}{{ page_title }}{% endverbatim %}. Dot notation ({% verbatim %}{{ object.attribute }}{% endverbatim %}) is used to access attributes, dictionary keys, or even call methods with no arguments, which keeps the template logic-free and easy to read.
