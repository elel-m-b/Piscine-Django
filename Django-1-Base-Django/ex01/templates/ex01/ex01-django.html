Django is a free, open-source, high-level Python web framework that encourages rapid development and clean, pragmatic design. It takes care of much of the hassle of web development, so developers can focus on writing their app instead of reinventing the wheel.

A Short History

Django was created in 2003 by web developers Adrian Holovaty and Simon Willison while working at the Lawrence Journal-World newspaper. They needed to build database-driven news sites very quickly, so they extracted their internal tools into a reusable framework. It was released publicly in 2005 and named after the jazz guitarist Django Reinhardt.

Why Django?

  • Batteries included: an ORM, an admin panel, a templating engine, an authentication system and more come built in.
  • DRY (Don't Repeat Yourself): Django encourages reusable code through template inheritance, model definitions and reusable apps.
  • Security: Django helps developers avoid common security mistakes such as SQL injection, cross-site scripting and cross-site request forgery.
  • Scalability: Django powers very large sites such as Instagram and Pinterest.

The MVT Pattern

Django follows the Model-View-Template pattern, a variation of the classic MVC pattern:

  • Model: describes the data structure (usually mapped to database tables).
  • View: contains the logic that processes a request and decides what data to show.
  • Template: describes how the data should be displayed (the HTML).
