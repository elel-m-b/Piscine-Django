A quick reference for the most common Markdown syntax.

Headers

# H1
## H2
### H3
#### H4
##### H5
###### H6

Emphasis

*italic* or _italic_
**bold** or __bold__
***bold italic***
~~strikethrough~~

Lists

Unordered

- Item 1
- Item 2
  - Nested item
* Item using an asterisk
+ Item using a plus sign

Ordered

1. First item
2. Second item
   1. Nested item
3. Third item

Task list

- [x] Completed task
- [ ] Pending task

Links

[link text](https://example.com)
[link with title](https://example.com "Title")
<https://example.com>

Images

![alt text](image.png)
![alt text](image.png "Optional title")

Blockquotes

> This is a quote.
>
> > Nested quote.

Code

Inline `code` in a sentence.

```
Fenced code block
no language specified
```

```python
def hello():
    print("Hello, world!")
```

Horizontal Rule

---
***
___

Tables

| Column 1 | Column 2 | Column 3 |
| :------- | :------: | -------: |
| Left     | Center   | Right    |
| a        | b        | c        |

Renders as:

Column 1Column 2Column 3
LeftCenterRight
abc

Escaping characters

\* not a bullet
\# not a header
\[not a link\]

Footnotes

Here is a footnote reference.[^1]

[^1]: This is the footnote text.

Line breaks

End a line with two or more spaces, or a blank line between paragraphs, to start a new one.
