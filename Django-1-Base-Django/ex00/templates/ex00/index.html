Markdown is a lightweight markup language that lets you format plain text using simple, readable symbols. It is widely used for README files, forum posts, documentation and note-taking because it is easy to write and easy to read even before it is converted to HTML.

Headings

MarkdownResult
# Heading 1Largest heading
## Heading 2Second level heading
###### Heading 6Smallest heading

Text Emphasis

MarkdownResult
*italic* or _italic_italic
**bold** or __bold__bold
***bold italic***bold italic
~~strikethrough~~strikethrough

Lists

Unordered lists use -, * or +:

- Item one
- Item two
  - Nested item

Ordered lists use numbers followed by a dot:

1. First item
2. Second item

Links and Images

MarkdownPurpose
[link text](https://example.com)Hyperlink
![alt text](image.png)Image

Code

Inline code uses single backticks: `like this`.

Code blocks use triple backticks, optionally with a language name:

```python
print("Hello, world!")
```

Blockquotes

> This is a quote
This is a quote

Horizontal Rule

Three or more dashes, asterisks or underscores on their own line:

---

Tables

| Column A | Column B |
|----------|----------|
| Value 1  | Value 2  |

Special Characters

To display a character that would otherwise be interpreted by Markdown (such as *, _, # or `), escape it with a backslash, e.g. \*not italic\*.
